# 截题 · 学习导师

[下载 Android v0.2.3](https://github.com/helh1723-lang/JieTi-/releases/tag/v0.2.3) · [产品介绍 PDF](截题_产品介绍.pdf)

公开版本使用通用教学配置，不预置个人学校、考试目标、历史学习观察或 API 密钥。Android 当前为 0.2.3，Windows 源码为 0.2.1，本次 Release 提供 Android 优化包和完整源码。

Android 平板上的悬浮答疑工具，以及 Windows 学习手记。界面采用暖米白、深灰与鼠尾草绿，顶部导航、单栏阅读，输入区随内容展开。数据优先保存在自己的设备，平板独立调用 AIPING。

导航、输入和悬浮窗采用液态玻璃方向的材质：凸起边缘、局部流动高光与柔和过渡；用户消息靠右，导师回答靠左。Windows 支持本页面背景的边缘折射；Android 透明表面实时透过底层界面，使用边缘光照模拟，不采样历史截图。悬浮球拖动时轻微流体形变，松手后回弹。支持减少动画，截图时立即隐藏悬浮控件。[材质原理、实现边界与实测](docs/liquid-glass.md)；[动效说明](docs/motion.md)。

当前 Android **0.2.3**、Windows **0.2.1**。学习规划按课程章节整理；Android 0.2.3 缓存两门课的统计、隔离建库进度更新、预计算讲义关联，并提供非 Debug 的 R8 优化包，个人构建已在荣耀平板保留数据覆盖升级；公开通用包另行构建验证。[本轮实机结果与边界](docs/performance-0.2.3.md)；[此前性能修复](docs/performance-0.2.2.md)；[章节规划](docs/curriculum-0.2.1.md)；[日练能力](docs/bugfixes-0.2.0.md)。

## 开始使用

1. 在 [v0.2.3 Release](https://github.com/helh1723-lang/JieTi-/releases/tag/v0.2.3) 下载 `Jieti-0.2.3-tablet.apk`。这是启用 R8 与资源压缩的非 Debug 通用优化版，使用个人测试用 Android Debug 证书；应用商店正式发布需要独立签名。升级时核对签名并覆盖安装，不卸载、不清空数据。
2. 打开平板应用的“设置”，填写 AIPING Key、Base URL 和模型名，保存后测试。默认地址为 `https://aiping.cn/api/v1`。
3. 导师模型需要图片输入、流式输出和工具调用；后台整理需要图片输入。其他角色可复用导师模型。文字资料的本地检索无需嵌入模型。嵌入模型配置保留用于兼容旧版。
4. 点击“开始悬浮学习”，允许悬浮显示和本次屏幕捕获。单击悬浮球框选，预览后发送；拖动移动，长按继续上一题。发送、补拍和收起后重开会保留本次学习会话的窗口位置与尺寸；对话区直接使用透明阅读层，不在回答出现时叠加白底；底部为单条输入栏，左侧“＋”展开截图、教学方式、学科、图解、重试和完成操作，右侧选择自动思考、快速或深入思考，发送中同一按钮切换为停止。“收起”返回悬浮球；悬浮球上的“×”、小窗右上角“关闭 ×”、通知栏“结束学习”都会退出悬浮功能并释放屏幕捕获，保留已保存题目。再次使用时重新点击“开始悬浮学习”。
5. 使用 Windows 安装包，或解压便携 ZIP 后打开“截题.exe”。两端接入同一 Wi-Fi／热点，在电脑开启配对，用平板扫码或粘贴完整配对信息。
6. 已配对设备在电脑开启同步窗口后，于平板点击“开始同步”。首次配对信息5分钟有效且仅用一次；之后复用可信设备凭据。一次只运行一个同步会话；数据同步与复盘文档生成分别显示结果，可取消后续传。

API Key 只保存在 Android Keystore 加密的本机配置中，不同步、不导出。桌面应用没有代填 Key 或接管网页 ChatGPT 的功能。

## 学习规划与每日三题

0.2.1 改为章节式学习工作区：信号与系统 按讲义整理为数学基础及七章共 52 个知识点，统一展示熟练度、学习要点和本周安排。所有章节、题目均纳入学习；第六章只有目录，标为待补讲义。数学按高数 9 章、线代 6 章、概率统计 8 章分组，共 23 章、157 个知识点，与用户板书资料对应。详见 [本轮变更与验证](docs/curriculum-0.2.1.md)。

在平板打开“学习规划”，设置学习目标和每日时间，点击“更新安排”。模型可沿用导师模型或在设置中单独选择。每日三题从已上传资料与联网题源中挑选完整原题；拍照或从相册上传手写步骤（最多6张，也可补充文字）后提交讲评，查看提示或原文会按辅助完成记录。能力判断会随新证据更新。

联网题源可在设置的“学习规划与题源”配置元宝、Tavily、博查接口，并测试已保存配置；未配置搜索时仍可从资料库选题。题目保留资料页码或网页来源；“来源标注”不是官方真题认证。资料未读完整或题源不足时显示缺口，补充资料后再补齐。

## 学习、记忆与教学进化

- 默认轻提示，提供“再提示一点、检查步骤、完整讲解、总结同类题”。截图求助先作为学习记录，诊断后分类。
- 后台整理、核验、记忆提取和教学评测使用独立角色。前台答疑优先，后台任务排队且可恢复。
- 稳定档案、明确偏好、推断偏好、学习证据、知识掌握与策略版本分别持久化。公开版使用通用教学配置，不预置个人背景或历史学习弱点。
- 不必说“记住”：日常追问、对图形/例子/推导的选择和理解反馈会积累观察；至少两条独立用户消息支持后才影响默认教学风格，相反偏好同样需要新证据。明确的“记住／以后都……”优先；“不要记住”与引用文字不会误建记忆。模糊的遗忘请求可在记忆页准确选择记录。
- 一次错误不会成为永久知识缺陷。独立掌握需要至少三道无提示独立完成的记录，跨至少两个北京时间日期；只计算最近30天的新鲜证据，近期错误会使旧结论降级；无新证据超过30天显示需要更新。
- 记忆页支持纠正、暂停、锁定和遗忘。遗忘规则阻止旧副本及旧证据重建记忆；原始题目／对话保留作为原始记录。
- 习惯学习每次对话都可发生，不要求手动完成题目；完整策略评测需至少3道有答疑过程的题、8轮新回答，并设置24小时自动冷却。固定案例与最近首问回放由模型评分，通过后观察前5次适用回答。评测失败保持当前版本，可恢复旧版，也可分别关闭对话习惯学习与自动策略评测。模型评测不构成数学正确性的保证。
- API 用量随扫描页识别和教学评测次数增长。文字资料入库无需 API 调用。教学评测包含基线、候选与核验请求；资料导入默认完整处理，可暂停续建。

## 资料与导出

支持文字／扫描 PDF、图片、DOCX、TXT、Markdown。两端可导入，平板本地建立全文检索索引；文字 PDF、DOCX、TXT 和 Markdown 不等待远程向量化。PDF 按页先建立文字索引，再核对公式与图表；视觉核对失败时文字仍可检索，并显示待核对状态。引用可回到原资料页。

资料和题目均可编辑、删除；资料可重命名、改学科、添加优先参考的补充纠正。题目可修改题干、步骤、诊断、解析、知识点和分类，后台 AI 保留手工修改。删除通过标记同步，旧副本不能复活，原始附件保留。连续对话保留原题、按题读取最近上下文，支持停止及不重复提问的重试。

Android 0.1.6 增强小球慢速与普通拖动时的流体形变和松手回弹，见 [0.1.6 修复记录](docs/bugfixes-0.1.6.md)。0.1.5 移除玻璃背景和边框对旧截图的采样，荣耀平板实机换色验证见 [0.1.5 修复记录](docs/bugfixes-0.1.5.md)。0.1.3 的截图边框折射仅为历史实现，当前版本已移除。

Android 0.1.2 悬浮窗与真实接口验收见 [本轮修复记录](docs/bugfixes-0.1.2.md)；上一版见 [0.1.1 修复记录](docs/bugfixes-0.1.1.md)。

电脑在成功同步后自动生成北京时间当天更新题目的两份文档：

- `给GPT的学习复盘.md`：有效记忆、题目转写、对话证据、诊断和复盘问题。
- `我的错题复盘.pdf`：原题截图、练习区、解析区与图解说明。

文档、截图与机器可读清单位于电脑应用数据目录的 `learning/exports/日期-版本/`，每次生成保留新版本。网页 GPT 复盘时上传 Markdown 和 PDF 两份文件。电脑顶部可导出当前题目或全部记录。

两端采用修订版本和共同祖先进行字段合并。同字段冲突保留双方版本，在电脑“设备与同步”中解决；删除和遗忘不会被旧副本恢复。

## 开发与验证

```powershell
npm ci
npm run verify
npm run desktop
# Android 源码、公式资源和协议已包含；本机脚本会复制到 ASCII 临时路径构建
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1
# 个人平板优化包：非 Debug、R8、资源压缩，兼容已有个人安装的签名
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1 -Tablet -Instrumentation
# Windows 打包
npm run package
```

`scripts/build-android.ps1` 使用 Gradle Wrapper；需配置 JDK 17 与 Android SDK，设置 `JAVA_HOME` 和 `ANDROID_HOME`。其他机器可调整脚本中的 SDK／Gradle 路径，或在 ASCII 路径使用 `android/gradlew.bat`。

协议源为 `shared/protocol.schema.json`，`npm run generate` 同步生成 TypeScript 和 Kotlin 类型。Room 与 ObjectBox 的结构文件需随源码保存。当前 Room 数据库版本为2，包含保留数据的1→2迁移；后续升级必须添加迁移，禁止破坏性清库。

测试数据严格标记为“自编验收”，使用 `.runtime` 隔离目录。安装、截图与索引基准可使用安卓模拟器；荣耀平板的保活、手写笔和权限行为仍需实机验收。最新结果见 `docs/verification.md`。
