# 架构与数据约定

## 工程结构

- `android/app`：Compose 主界面、MediaProjection 悬浮捕获、Room 持久化、WorkManager 后台任务、AIPING 访问、本地全文检索（保留 ObjectBox 旧索引兼容）、TLS 同步客户端。
- `desktop/core`：协议验证、SQLite 存储、共同祖先字段合并、遗忘规则、TLS 同步服务和导出数据组织。
- `desktop/electron`：受限 IPC、桌面文件选择、资源协议、PDF 打印与窗口生命周期。
- `desktop/ui`：本地 React 管理界面，模型生成的任意 HTML 不进入桌面受信渲染器。
- `shared/protocol.schema.json`：跨端协议唯一来源；`scripts/generate.mjs` 生成两种语言类型。

## 持久化

记录使用 UUID 修订号、父修订号、设备标识及不可变历史快照。跨端不依赖设备时钟决胜。时间仅用于排序与北京时间报表。

SQLite/Room 保存结构化事实；原文件按 SHA-256 独立存放。附件先完整校验，再提交关联记录。资料默认本地分块与全文检索，不等待在线 embedding；保留旧向量实体结构供历史安装兼容。Room schema 和 ObjectBox UID 模型在仓库中保存，以便后续迁移。

服务端合并成功的记录仅在客户端本地修订仍与本次上传一致时接受；上传期间的新修改不能被合并响应覆盖。冲突双方同时保存在电脑冲突队列和客户端历史中，客户端接收电脑当前版本，等待人工解决后下一次同步接收最终修订。

## 记忆与策略

记忆拥有来源、作用域、确认方式、置信度、观察时间、有效状态与锁定标志。稳定背景和历史观察来自用户提供的教学提示词；每次对话只召回相关且有效的记忆。

召回序列化数据使用 UTF-8 字节预算保守约束，默认3000字节，并仅附最近3个来源ID；数据库仍保存完整来源关系。学习事件和知识快照单独按学科与知识点筛选。推断不覆盖明确偏好；暂停／锁定记忆不因后台提取重新启用。

遗忘生成持久化 ForgetRule 和记忆删除标记。相同作用域与键、相同旧来源的重建均被阻止。明确删除优先于旧副本，跨端不允许通过字段冲突恢复已遗忘内容。

策略通过候选、评测、观察、启用、退役或回退状态流转。评测缺字段、分数无效、出现关键违规、任一案例退化或整体没有提升时均不能自动采用。历史回放只使用题目和最初用户输入。评测来自模型，不能代替人工数学复核。

日常对话由独立 learn 任务提取教学习惯，必须引用用户消息 ID 与原文，至少两条不同来源才采用；推断状态支持候选、有效及被新观察替代，尊重人工锁定与遗忘。完整策略评测按 3 道对话题、8 轮新回答和 24 小时冷却触发，不依赖用户手动标完成。

## 同步接口 v1

- `GET /health`：协议与就绪状态。
- `POST /pair`：一次性配对凭据换取设备令牌，5分钟有效、成功后作废。
- `GET /manifest`：记录ID与修订。
- `POST /records/push`：最多100条记录，返回接受版本与冲突。
- `POST /records/pull`：最多100个ID。
- `HEAD /assets/:sha256`：已保存状态与续传偏移。
- `PUT /assets/:sha256?offset=&total=`：追加附件分块，完成后校验哈希。
- `GET /assets/:sha256?offset=`：每次最多1MiB。
- `POST /complete`：同步批次完成，生成当天复盘文档。

配对以外需要 Bearer 设备令牌。平板固定验证二维码提供的叶证书指纹，拒绝证书变化。电脑停止同步窗口即停止监听；设备令牌只保存哈希，平板凭据由 Keystore 加密。

## 生成页面

先从 Markdown 中保护完整公式片段，再用 DOMPurify 清理正文，只在文本节点恢复安全的 KaTeX 输出；历史消息的 DOM 在流式更新时保留。生成 HTML 放入仅允许脚本的独立 iframe，不授予 same-origin、导航、弹窗、表单或原生接口；CSP 阻止外部连接，仅允许内置字体与内嵌图像。KaTeX 启动代码由应用注入。页面显示后保存静态视口快照，导出同时保留文字说明。卡死或渲染异常退回文字说明。

生产设置和真实 Key 不进入源码、协议或诊断输出。测试夹具只使用明确标记的自编题目。
