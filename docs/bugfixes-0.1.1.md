# 截题 0.1.1 修复记录

本轮覆盖资料导入、公式、人工管理、连续答疑和自主习惯学习。保留液态玻璃、左右对话布局、本地数据及既有 API 配置。Android 仍使用同一 Debug 签名，Windows 未配置发布者签名。两端请同时更新到 0.1.1。

## 资料库

原先每批文本都等待在线 embeddings，PDF 每处理 8 页就重新进入后台队列；没有正确配置嵌入模型时，文字教材也不能正常建库。

- 改为本地全文检索优先。文字 PDF、DOCX、TXT、Markdown 不调用远程嵌入接口，普通文字资料不需要 API Key 即可处理。
- PDF 按页提取、按页提交，已完成的页面马上可检索；没有每 8 页一次的强制排队。长任务仍保留断点和时间预算。
- 扫描页、图片和明显提取异常的页面仍需视觉模型识别。识别进度、失败页和已处理页数可见，失败不抹掉已有索引。
- 暂停、继续、手动重试可以控制处理；资料处理与长时间教学策略评测使用不同任务锁，前台答疑到来后后台让出后续处理。
- 修复 Android 不支持原 DOCX XML 解析选项导致的导入失败，导入和原文查看共用流式解析器。
- 检索采用本地关键词/中文分词评分及文档分散，不宣称等同于 NotebookLM 的云端检索质量；真实教材效果还需验证。

## 公式与对话显示

原先先解析 Markdown 再找公式，`\(...\)` / `\[...\]` 的反斜杠可能被当作 Markdown 转义，公式中的下划线、矩阵行和表格竖线也可能被改变。

- 两端共用公式保护与清洗流程，先识别完整数学片段，再处理 Markdown；代码示例、未完成的流式公式和转义货币保持原文。
- 支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`；KaTeX 保持不执行不可信命令，非法输入有可见降级。
- 流式对话只更新内容变化的消息，保留历史 DOM 节点与阅读位置；约 80ms 合并一次可见更新。
- 普通追问不再销毁并重建整个悬浮窗；WebView 重载会重新绘制已有内容。

## 编辑与删除

- Android 可以编辑题目标题、题干、步骤、诊断、解析、知识点、学科和分类；Windows 可以修正标题、转写、步骤、诊断、解析和分类。
- 资料支持重命名、改学科、补充纠正和删除。补充纠正作为独立来源优先提供给导师；原文件保留。
- 手工修正字段会被标记，后台整理不得覆盖。编辑期间仅处理进度变化不会导致整份草稿无法保存；同字段真实冲突仍保留草稿。
- 删除需要界面确认，生成可同步的删除标记，关联对话/引用/学习证据退出当前数据视图；资料分块退出检索。旧副本和晚到子记录不能复活。
- 原始附件和修订历史保留，未执行物理清库或卸载。依赖已删对话的未锁定推断偏好会降为候选或退出使用，相关掌握证据会刷新。

## 连续答疑

- 按题查询消息，避免每次扫描全部对话。
- 请求携带本题题干、学生步骤及原始截图；最近上下文有字符与消息数预算，长对话不会挤掉原题。
- 发送时立即占用会话，阻止双击并发；其他请求尚未结束时不清空新输入。
- 停止后可重试同一条用户消息，包括刚发送就停止的情况；不会重复保存同一问题。未完成回答不计入学习证据。
- 保存后的回答用消息 ID 与流式内容衔接，避免闪空或重复；连接提前结束会报告中断，不把半截响应当完整答案。
- 自动图解转为后台生成，文字回答无需等待另一整轮页面生成。

## 自主习惯学习

无需说“记住”，也不要求先点“完成本题”。

- 日常追问、选择解释方式及理解反馈会积累教学观察；先支持详略、提示粒度、图形/符号、例子/原理顺序四类。
- 简单对话请求可本地形成观察；对话空闲后，独立学习任务分析近期师生交流，模型必须引用实际用户消息 ID 与原文短句。助手自己的话、教材和图片不作为用户习惯证据。
- 一条证据为待验证观察；至少两条不同用户消息支持后才进入默认偏好。重复处理同一消息不会增加次数，相反习惯也需新证据，避免同时采用矛盾默认。
- 明确要求优先，锁定、暂停、纠正和遗忘继续有效；本次提问的要求优先于长期习惯。
- 完整教学策略评测改按实际答疑积累触发：至少 3 道有对话的题、8 轮新回答，自动评测有 24 小时冷却。固定教学案例和首问回放仍需通过评测才采用，保留观察和回退。
- 平板“导师进化”可分别关闭习惯学习和自动策略评测；“记忆”页可以审阅每条观察及来源。
- 习惯学习通过可编辑记忆和提示上下文生效，不是修改模型权重。真实模型推断与长期教学效果尚待真实使用验证。
