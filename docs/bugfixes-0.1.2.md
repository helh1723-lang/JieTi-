# Android 0.1.2 · 悬浮窗统一与接口实测

日期：2026-10-23。包名 `cn.jieti`，versionCode 3，Android Debug 签名。

## 实现变化

- 默认底部仅一条输入栏：左侧“＋”，右侧思考选择与发送／停止。截图、教学方式、学科、图解、重试和完成放入可滚动展开菜单；教学方式和思考模式均可直接选择。
- 标题、菜单与输入栏使用统一文字、圆角和触摸涟漪。取消各按钮独立的白／绿底板、抬升回弹与悬浮窗周期扫光。
- WebView、HTML 正文和导师回复透明。收到回答不改变背景，不添加阅读白底；图解生成也要求透明主背景。
- 截图隐藏控件与键盘，保留面板及 WebView；取消截图、补拍、预览、发送到返回均复用当前窗口。裁切压缩与保存放到 IO 线程，保存过程中保留框选画面，避免短暂露出底层画面。
- 吸边约260ms，每帧更新真实 WindowManager 坐标，取消内部 translation 后再跳转窗口的路径。再次按下可打断吸边，减少动画模式立即定位。
- 连续对话明确将旧截图／题干／检索作为参考，最新条件优先；上下文末尾明确引用本轮学生原文，保留原题和近期完整轮次。
- 数据库、权限及已有学习记录保留；安装使用 `adb install -r`。旧安装包另存保留。

## 真实接口范围与模型边界

使用用户明确授权的本地 env 中的 AIPING Key，保持源文件只读。密钥只经标准输入传入应用私有临时文件，测试启动即删除；独立设置由Android Keystore加密，结束清理。源码、APK、日志及证据中检查未包含此Key。

实际测试范围：`GET /models`、流式和非流式 `/chat/completions`、快速／深入思考开关、无效Key错误提示、进行中取消、archive／verify／artifact／strategy JSON、工具参数流与工具结果往返、图片OCR与本地检索、截图Agent与多轮对话、整理核验、图解持久化，以及 `/embeddings` 的两条1024维向量。

模型目录接口本身可公开返回，不能用获取目录成功认定Key有效；鉴权测试使用实际对话接口。思考开关遵循 [AIPING 文档](http[LOCAL_PATH]) 的 `enable_thinking`，自动模式不强加此参数，部分模型服务可能不支持开关。

35B快速模式在独立中文多轮合成测试中出现旧结果5或误算7，断言期望6；消息顺序与末条请求已检查正确。这暴露了模型层的上下文／数学可靠性问题，不能仅凭HTTP成功宣布答题正确。保留同一数值断言，使用更强的 Qwen3.5-397B-A17B 交叉复验，并强化最新请求在上下文中的显式引用。最终快速模式的中文多轮数值断言仍失败，因此完整真实接口套件为 PARTIAL，而非全绿。将捕获到的同一请求直接重放给397B模型：`enable_thinking=false` 返回5，`true` 返回6，已确认思考模式会实质影响此用例；深入模式仍不构成通用正确性保证。保留原失败断言，未改成只检查非空。

## 复现工具

`scripts/build-android.ps1` 执行单元测试、lint和APK构建；输出名从versionName读取，保留旧版安装包。`scripts/test-emulator.ps1`运行设备回归。

真实测试需显式设置 `JIETI_TEST_ENV` 指向已授权的env文件，可设置 `JIETI_TEST_MODEL` 选择模型；运行 `scripts/run-live-provider-test.py`。UI验收使用 `scripts/test-glass-overlay.py`，仅面向当前脚本明确指定的测试模拟器，使用临时合成题库。测试不会代替荣耀平板实机动效、长时间帧率、耗电、手写笔或模型教学质量验收。
