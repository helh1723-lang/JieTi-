# 0.1.4：公式、相关图解、自动笔记与玻璃可读性

历史记录：此版本的截图柔焦和边框截图采样在 0.1.5 中移除，当前玻璃保持底层实时透视，见 [0.1.5 修复记录](bugfixes-0.1.5.md)。

本次以 USB 连接的荣耀平板 V8 Pro（Android 14）上的真实题目为复现依据，保留原安装包、数据库、原图和历史记录后更新安装。私有备份位于 `.cache/device-0.1.4/`，不进入公开交付证据。

## 修改

- 原题、后台复盘和笔记共用富文本与公式渲染。修复独立公式嵌套块元素的问题；旧记录中的 `X1`、`Φ`、概率事件大括号和普通文本公式做显示兼容，不改写原始作答。长公式可以横向阅读。题目原图区域限制高度并允许滚动。后续后台整理要求输出标准 LaTeX，并分别记录题干与学生步骤。
- 图解生成同时使用原图、题干、学生步骤和最近对话；最新用户条件优先。信息不足时返回明确说明。生成期间题目被删除或上下文更新时，不保存过期结果。已完成本轮回答与图解通过消息 ID 关联，图解直接显示在对应回答下方。
- 模型根据内容选择文字、列表、公式、对比表或交互图解，不强制每轮生成图。本次没有添加论文、网页抓取或联网阅读功能。
- 图解在隔离 iframe 中运行，只开放脚本；禁止联网、存储和原生调用。补上 iframe 内的离线 KaTeX 自动渲染及字体跨域响应。
- `+ → 玻璃模糊度` 提供 0—100 滑动条并保存设置。支持系统实时背景模糊的设备使用窗口背景模糊；关闭或不支持时采用已有截图柔焦与玻璃雾度降级。`+` 展开区域有更强的磨砂玻璃承托。正文不会一起模糊，也没有恢复白色回答底板。
- 笔记 Agent 默认整理条件识别、选工具的理由、考场前 30 秒启动步骤、边界自检和不附答案的迁移自测。前台批改与后台诊断冲突时明确保留待核对项。手动保存后的笔记停止自动覆盖；生成结果提交时做事务内版本检查，保护同步和手动修改。旧反馈记录不会再误当成“我的笔记”。
- 桌面端同步兼容新的可选字段；同步后的 Agent 笔记支持阅读预览与编辑，手动修改会保留为用户笔记。使用同步时应同时更新桌面端到 0.1.4。

悬浮窗保留原有边缘流光、1.10 倍窄边折射，以及截图时复用窗口和 WebView 的行为。用户后来反馈拖动、缩放与边框异常又自行恢复，并取消该项追加修改；本次没有在取消后调整这些参数。

## 验证与边界

- `npm run verify`：16 项测试通过，TypeScript、桌面及 Android 渲染器构建通过。
- Android：10 项 JVM 测试通过，lint 通过，应用与测试 APK 构建通过。
- 真实旧题的转写、步骤、诊断和解析共 45 处公式：KaTeX 严格解析 0 错误。
- 最终平板验收 14 项全部通过，覆盖空上下文拒绝、图解消息关联、笔记去重与手动保护、删除后的迟到结果、流式页面保持、离线字体、原图上下文、重试取消、资料检索，以及边缘动画与折射。
- 真实概率题：原先错误生成二次函数图；本轮重新生成全概率公式与开关变量分支图解。自动笔记包含前后台批改不一致的核对提示，没有把助手补出的步骤当成学生独立完成的证据。
- 合成 TCP 对话：候选测试中模型选择状态比较表，最终测试中主动调用图解工具并生成握手状态与报文方向图，已验证图解关联到本轮回答。允许按内容返回表格或图解，不把“必须出图”作为正确性标准。最终记录见验收日志。
- 打包后的桌面程序在 E 盘隔离资料库完成启动、公式、资料编辑、删除与流式节点保持验收。未对用户桌面资料执行编辑、删除或导出。
- 悬浮窗已实测框选、预览恢复与取消。平板报告系统未开放实时跨窗口模糊，使用截图柔焦与雾度降级；不是实时读取所有底层画面。没有以静态截图证明所有帧都完全无抖动。
- 本轮重点重测修改过的导师对话、视觉图解和笔记整理链路；models、embedding 等既有接口的更完整验收保留在 0.1.2 记录中，本轮没有重跑所有旧接口与所有模型组合。

模型仍可能误读手写或产生错误结论；本次真实记录中发现了前台与后台批改分歧，保留原图、来源和待核对提示，不把模型输出视为数学证明。
