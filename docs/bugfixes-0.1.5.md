# 0.1.5：实时透视玻璃与小球流体拖动

修复悬浮窗仍透出此前截图的问题：移除面板、菜单、小球背景与边框中的截图采样、截图柔焦缓存和静态透镜。内存截图只用于框选、重裁与发送预览，不进入材质绘制。

面板通过透明材质显示当前底层应用。系统开放跨窗口模糊时使用原生实时背景模糊；未开放时滑动条调整玻璃雾度，仍保持实时透视。本次荣耀平板 V8 Pro 的系统未开放跨窗口模糊，因此不声称此设备实现了真实背景模糊或放大折射。保留凸起边缘、双层轮廓和慢速流动高光。

小球根据拖动速度和方向轻微拉伸并收窄尾部，停止移动和松手后通过阻尼弹簧恢复。形变只改变绘制轮廓，窗口坐标和点击区域保持稳定；回边沿用位置动画，快速再次拖动可中断回边。系统停用动画时关闭形变，移除小球时清理帧回调。

## 验证

- Android 构建、lint 与 14 项 JVM 测试通过，其中新增 4 项弹簧测试，覆盖速度归一化、帧间隔、极值约束、释放及打断。
- 荣耀平板 V8 Pro / Android 14 上 14 项原生回归通过，包含实时背景颜色合成、全雾度范围、弹性轮廓恢复、重复重绘、边缘流光，以及公式、图解、笔记等既有路径。
- 真实屏幕捕获：先框选绿色合成背景，取消待发送截图后切换为红色、蓝色；面板窗口对象保持不变。面板采样分别为 RGB(211,93,88)、(87,93,212)，小球分别为 (214,50,47)、(46,50,216)，均跟随当前底层颜色，没有保留绿色截图。
- 实机执行两次拖动，录制拖动、释放与回边；未误触打开面板或截屏，最终停靠屏幕边缘。录像抽帧确认轮廓随拖动变化并恢复。录屏自身的帧率不等同于应用帧率，没有进行长时性能/耗电测试。
- 独立测试背景页仅在测试 APK 中，不进入交付应用。首轮 Kotlin 测试页独立启动发生异常；改为只依赖 Android 类的 Java 测试页后，确认其保持前台再完成上述验收，未把未显示测试背景的结果计为通过。
- 更新安装使用原有签名并保留数据。交付包与设备已安装包 SHA-256 一致；结束时主进程仍在运行，近期进程日志未见 FATAL EXCEPTION / ANR。测试不调用 AI，不新增学习记录，不更改现有 API 设置。

合成背景截图、拖动录像、结果 JSON 与原生测试日志位于 evidence/0.1.5（原始诊断未公开）。原有用户题目和测试失败时涉及真实界面的截图不进入该目录。
