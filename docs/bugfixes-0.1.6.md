# 0.1.6：增强小球流体拖拽

0.1.5 的形变幅度和低速响应过小，普通平板拖动时难以察觉。本次仅调整小球的轮廓、速度响应和弹簧反馈，不改动截图、AI、存储、窗口拖动或吸边算法。

- 慢速也有反馈：120dp/s 的目标响应由约 0.13 提高到约 0.60，随速度平滑增强并限制最大值。
- 前端鼓起、尾部明显收窄，增加身体向后滞后的液滴轮廓。填充、高光和阴影共用形变轮廓；文字、图标和点击区域保持稳定。
- 提高响应速度、降低弹簧阻尼，松手后出现可见的反向回摆，再逐渐恢复。停住手指时先短暂保持、再平滑放松，避免一停就突变。
- 保留固定窗口尺寸，为绘制增加 1dp 留白，约束斜向形变的曲线控制点，保证边框不被窗口裁切。减少动态效果的系统设置仍会停用形变。
