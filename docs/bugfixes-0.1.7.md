# 0.1.7 体验与可靠性优化 · 2026-10-24

本轮范围：用户指定的玻璃可读性、草稿、Android 流式性能、请求结束状态、同步、长期记忆、教材检索及对话图片。沿用暖米白、鼠尾草绿与统一玻璃控件。

## 行为约定与修复

| 问题 | 当前结果 | 回归边界 |
|---|---|---|
| 复杂背景下的阅读 | 悬浮窗默认阅读优先，提高原有玻璃面的雾度；支持在更多菜单中切换。深浅色主题使用同一语义文字与玻璃调色板，桌面通知与编辑区也提高现有材质的遮蔽率 | 不增加独立回答底板；保留模糊度、窗口拖动、截图预览与紧凑输入区 |
| 笔记草稿丢失 | 两端按题目保存本地草稿与基准版本；切页、重进后恢复。保存成功才清理草稿；同步冲突保留草稿。Android 输入也在本地保护 | 草稿不自动成为正式笔记，不进入同步记录或记忆证据 |
| 流式更新重复工作 | WebView 只传输变更消息及新增文字（流式回答不再每次重传完整正文）；只有顺序变化才传 ID 顺序，只有图解变化才传图解；公式资源每个阅读页初始化一次，DOM 按消息 ID 复用；回答使用 StringBuilder | 保留现有 80ms 输出节流、KaTeX、离线图解沙箱与历史原图 |
| 对话看不到已发图片 | Android 主界面、悬浮窗、桌面对话均按 message.assetIds 显示本地图片，可折叠 | 不把图片字节反复传入 JS；本地媒体仅允许已校验的附件哈希，继续阻断外网与文件访问 |
| 请求误判完成 | 只有 stop / 完整 tool_calls 走正常路径；length、content_filter、异常终止、缺少结束原因分别处理。未完成文字保留为带状态的消息，不进入模型历史、后台整理和学习证据；导出显式标注草稿 | 重试沿用原用户消息；401/403 不后台重试，429/5xx 等暂时错误允许后台有限重试；归档/图解等结构化请求显式使用 JSON 对象模式，避免 LaTeX 非法 JSON 转义，OCR 保持纯文本 |
| 重复同步与导出混淆 | 进程内互斥与忙碌状态共同阻止重复会话，允许取消与续传。数据成功后立即记 lastSync；电脑异步生成文档，独立报告成功、失败或仍在后台生成 | TLS 指纹校验、附件哈希、分块偏移、冲突与删除语义不变；同一导出进行中不重复启动 |
| 旧掌握结论不降级 | 依据最近30天、不同题目的最新结果计算；新错误使旧掌握结论降级，重新积累三道无提示成功且跨两天后恢复；用原用户证据日期防止重新归档刷新证据年龄 | 不把一次错误固化为永久能力标签，保持来源可追溯 |
| 否定或引用被记住 | 先识别否定，再识别直接指令；引用、代码块与普通“以后”描述不作为明确记忆。禁止本轮记忆时记录来源阻止规则，后台也不再从该来源提取 | 保留明确偏好优先、锁定、暂停、遗忘、旧副本阻断与重新明确授权 |
| 教材检索不匹配 | 不跨语言/空白拼接双字，过滤提问套话；扫描所有匹配候选，按词区分度、覆盖率与片段长度排序，拒绝低相关命中；引用绑定具体回答，不把旧回答出处显示为本轮依据。根据用户补充的“数学题返回信号与系统基础讲义”样本，增加主题学科路由、工具显式学科参数及资料标题与学科的一致性过滤 | 无需 embeddings，也不调用模型建文字索引；维持学科过滤、删除级联、原页与补充纠正 |

## 兼容与回退

- Room 仍为 v2，不使用破坏性迁移。更新安装使用 `adb install -r`，保留学习记录。
- 协议增加可选 Message.completion / Citation.sourceMessageId，桌面与 Android 应同时升级到 0.1.7；旧记录按已完成内容兼容读取。
- 旧版安装包保留。修改前源码副本在 `.cache/optimization-before-20261024/`；本目录没有 Git 元数据，未擅自初始化仓库或上传。
- API 密钥只经显式授权的外部 .env 读取，在临时、隔离的测试配置中使用，不写源码、同步记录或发布包。
