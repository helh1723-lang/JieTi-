# 0.1.8 · 条件、同步、资料与定位升级

2026-10-24。范围仅包含用户指定的七项优化和悬浮配色；单题导出范围、结构化数值图解等其他建议不在本轮。

## 行为变化

1. **连续离线修改不再产生伪冲突**：两端按批交换修订历史，沿共同祖先合并。合并版本保存双方父版本，避免下一次编辑丢失另一分支。手工字段保护集合可合并；真正同字段分叉仍保留双方版本。删除、遗忘仍优先，墓碑记录不重新传输其旧内容。
2. **旧条件结果不能提交**：题干、步骤、截图、学科、当前条件及相关对话形成输入摘要；归档与独立核验均结束后，在同一数据库事务内复核，再提交诊断、解析和证据。期间修改或删除会丢弃旧结果并安排重新整理。已生成的证据、图解和自动笔记在条件变更时失效；手动笔记保留。证据、回答和分析结果保留输入来源摘要，旧条件之前的作答不被重新标成新条件下的独立掌握。
3. **手动学科优先**：用户选定或手改的题目学科标记为手工来源。自动判断用于本轮检索，不覆盖手工学科。旧版未手工固定的自动分类仍能纠正。分类与检索范围分别保存。
4. **当前条件独立持久化**：明确的“改成／纠正／后面按……”等条件更改按用户原文保存并保留来源消息；临时“如果……”单独保存，仅在对应当轮生效。长对话裁剪后仍独立注入当前条件。明确的标量参数赋值会先应用到当前题干，原始题干保持不变；每轮请求尾部携带当前任务快照，避免新旧参数并列造成歧义。主应用、悬浮工具菜单、桌面均可调整或恢复原题。自动识别主要针对明确修正语句，任意复杂条件可直接在该入口确认与修正。
5. **资料保真优先**：PDF 每页先建立本地文字索引，再核对整页图像，正文多的页面也不会跳过公式和图表。失败保留已提取文字、进度及质量提示。Word 保留常见 OMML 分式、上下标、根式、矩阵、积分及表格结构；逐张读取内嵌图片进行识别，避免一次加载全部教材图片。Word 原生图表提取数据并标记需要对照原文件；不支持的公式结构、图片格式和模糊区域明确标记待核对。原文件始终保留。
6. **资料记录去重**：再次导入相同内容时，默认复用已有资料记录、索引和进度；用户可明确保留独立资料。导入教材新版本会生成新的记录并保存版本来源，旧引用继续指向旧记录。不会擅自合并用户已保留的独立资料。
7. **定位到这里再提问**：原题、对话图片及教材原页可进入缩放阅读，双指缩放、拖动、圈选后点击“问这里”。发送消息保存局部图片、原图标识、归一化区域及来源，原图和裁图均参与附件同步。PDF 引用在能找到原页完全一致的文本片段时高亮；找不到时显示摘录与原页，允许用户自行圈选，不伪造位置。桌面提供原图缩放查看。
8. **统一悬浮配色**：设置 → 外观与阅读 → 悬浮窗配色。预选竹月 `#819A87`、天青 `#7D9DA4`、月白 `#B2BFC0`、藕荷 `#B49BAA`、秋香 `#A9A176`；也可填写自定 `#RRGGBB`，预览后应用。统一作用于已有玻璃面、边缘与控件，保留原有透明阅读层。文字随浅深主题保持语义色，不直接用用户选色充当正文色。

9. **连续的记忆阅读界面**：按用户补充反馈，两端移除逐条卡片、重复图标与标签框，用同一阅读背景、留白及轻分隔线组织记忆。操作收进每条记忆的更多菜单，依据按需展开；知识掌握沿同一阅读轴展示。保留纠正、锁定、暂停、遗忘能力。配色预选仅显示色点与名称，去掉解释文字。

## 数据与升级

JSON 协议增加可选字段，Room 表结构和数据库版本 2 保持不变，不清库、不破坏迁移。新增历史交换接口，两端请一起升级到 0.1.8。原文件及学习记录保留。Android 为 Debug 签名个人测试版；Windows 按已有配置不签名。

“公式与图表处理完成”表示相关识别流程已执行，并不表示每个公式都经过数学证明。清晰度不足、Word 原生图表样式或复杂公式仍需要对照原页确认。

## 验收记录

最终结果、数量与产物校验见 验收清单（原始诊断未公开），过程遵循 [本轮契约](upgrade-018-contract.md)。

- Node：25 项，含实际 HTTPS 历史分页、连续离线编辑、双父版本、真实冲突、去重及墓碑保护。
- Android JVM：21 项；完整单元测试、Lint 与 Debug/Test APK 构建。
- 模拟器：新旧条件竞争、长对话、手工分类、Word 公式/图表、图文 PDF 识别与失败保留、资料去重、新版本、缩放坐标、配色对比度及原有图片/流式/笔记回归。
- 曾观测到一次 35B 模型沿用旧参数（返回 4 而非 9），保留在 `live-provider-failed.log`；随后消除输入中的新旧题干歧义并复验。该失败不计为通过。
- 真实 API 抽验：`Qwen3.5-35B-A3B`，长对话外保存的新条件计算及分式/图表坐标轴与单位识别。
- 实际 Android → Windows TLS：离线连续修改十次，以及双方不同字段修改后的合并。
- 界面：模拟器实际圈选到消息保存；配色设置；Windows 打包运行、图片、笔记草稿及浅深主题截图。

本机 Gradle 注解处理器在受限进程中关闭缓存 JAR 时出现 AccessDeniedException；在常规本机权限下运行后通过，没有禁用处理器、测试或 Lint。旧有 KAPT 参数提示与构建体积提示保留。

荣耀平板的手写笔、长期保活及 OEM 权限行为未在本轮复测；模拟器和模型抽验不等同于真实教材的全面准确率评估。模型凭据仅用于授权测试的私有临时配置，测试后清理，不进入源代码、同步或发布包。
