# 截题 0.2.0 · 学习规划与指定修复

本版包含用户指定的七项修复、悬浮配色简化、连续记忆布局，以及学习规划 Agent 和每日三题。未扩展到原分析中的其他方向。Android 是独立运行模型、建库与练习的主端；Windows 同步查看规划、题目、讲评，并继续支持编辑与导出。

## 学习规划与能力更新

- 基于有效的学习记忆、题目、作答证据、掌握状态和日练记录安排七天学习；近期提问的知识点可用于诊断选题，不会被直接视为做错；模型返回不合规的步骤时保留对应的本地安排，保证七天完整；可设置目标与每日时间。
- 冷启动只标记待诊断；不会把求助、一次错误、看过解析或自述做对直接判成能力结论。
- 新作答完成后自动更新掌握证据并安排重新规划；开启时由 Android WorkManager 定期跟进，进入页面也检查当天安排。系统后台调度不保证固定时刻，设置中可关闭自动跟进。
- 作答区支持系统相机拍照、相册多选，最多6张，可仅上传照片，也可补充文字；照片本地草稿保留，可预览放大或移除，提交后随作答记录同步到电脑。讲评完成后收起编辑区，保留查看与修改入口，让识别结果和解析充分展示。图片按EXIF方向解码并控制尺寸，避免大图直接撑满内存。
- 多模态讲评先转写手写步骤，再结合原题核验，显示识别文字和讲评；看不清、缺页或低置信时保留未知并说明需补拍位置，不猜填公式。
- 独立讲评保留实际作答、原题、核验结果、置信判断与来源。低置信结果保留未知；看过提示或原文按辅助完成记录。不同题目与跨日证据共同支撑掌握判断，反复提交同一题不累加成多道题。
- 规划及讲评提交前重新核对输入；生成期间修改目标、题干或作答，旧结果不能覆盖新状态。

## 每日三题与题源

- 题源为用户上传资料库 + 搜索服务。设置可接入元宝、Tavily、博查，逐个测试；按已启用的服务顺序回退。密钥只保存在本机加密设置中，不参与同步。
- 联网查询只带学科和知识点关键词；本地资料与学习证据由用户配置的模型服务处理。
- 按知识点分别检索，含数学符号关键词辅助；逐页保留视觉核对内容与原始文字。未核对、无法辨认或条件不完整的内容不作为完整题源。
- 模型只能摘录题源中的连续原题，程序再校验原文、完整标记、答案泄漏、近期重复和来源版本。没有完整可靠题源时少于三题并说明原因，可补充资料后补齐，不编造真题。
- 保留资料名、页码或网页链接、原文引句及题干指纹。年份和真题标签显示为“来源标注”，不冒充官方核实。
- 当日题目使用固定槽位；刷新不替换已选题。历史练习保留同步，界面只加载当日题目。

## 指定修复与统一界面

离线历史链与分支合并、旧分析写回防护、手工学科保护、独立生效条件、公式图表视觉核对、资料记录去重，以及原图放大圈选发送，详见 [0.1.8修复记录](bugfixes-0.1.8.md)。

记忆页改为连续阅读轴和轻分隔线，纠正、锁定、暂停、依据和遗忘收进更多菜单。配色只显示色点与雅名，保留竹月、天青、月白、藕荷、秋香及自定色值，选中状态由组件呈现。规划页沿用同一套字体、控件和玻璃材质，一周安排默认折叠。

## 开发资料与验证范围

用户授权的考研数学目录作为只读开发语料，包含21份PDF和24段视频。此次用真实2024数学PDF对照文字层与原页，并测试公式视觉核对、题目选择和出处。没有将整套资料内置进APK，也没有实现视频自动建库。后续可通过应用正常的资料库入口上传PDF、Word、图片或文字资料。

验证记录见 验收清单（原始诊断未公开）。模拟器通过不能替代荣耀平板实机长期验收；模型讲评保留可核对依据，不代表数学准确性已被完全证明。

## 安装

Android与Windows需一起升级到0.2.0；新增规划、练习、作答同步记录，旧版严格协议校验器不兼容新类型。Android沿用原包名、Debug证书及数据结构，以覆盖安装保留用户数据；Windows安装包沿用项目的未签名配置。

真实接口抽验使用 Qwen3.5-35B-A3B：元宝返回10条题源；2024数学原PDF共17页，本轮特意在视觉核对第1页后暂停，抽得2道完整题并保留出处；自编草写/排版图像解答经真实视觉讲评判定正确。图像样例并非真实用户手写，不能据此声称任意字迹准确率。相机入口在模拟器拍到的是虚拟灰色画面，入口与回传已验证；用于讲评的图片由相册上传自编验收样例。
