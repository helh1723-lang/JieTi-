# 0.1.0 界面与悬浮退出修订

## 阅读布局

Windows 移除固定侧栏和题目/详情并排布局，采用顶部导航、记录列表与独立阅读页。主色改为暖米白、深灰和鼠尾草绿；深色主题同样使用暖灰与绿色。复盘笔记输入随内容增长。

Android 主页面压缩导航，进入题目后让出顶部空间。答疑输入采用无硬边框的圆角底部输入条，随内容增长；教学深度改为菜单选择，记忆依据、图解生成和反馈工具按需展开。悬浮小窗使用相同的暖色体系与柔和输入区。

## 关闭行为

此前小窗“×”调用收起逻辑，再次创建悬浮球，因此无法退出悬浮功能。现在：

- 悬浮球自带“×”，小窗右上角显示“关闭 ×”。两者执行统一退出流程。
- “收起”保留悬浮球；“关闭”移除全部悬浮窗口，停止前台服务、屏幕捕获和待执行的捕获回调，释放 ImageReader、VirtualDisplay、MediaProjection 与位图。
- 关闭不会杀死主程序，也不会删除已经保存的题目、对话或记忆。重新开始时通过系统重新授权捕获。
- 旋转屏幕重新适配悬浮球和小窗；预览图、未发送草稿、学科与教学模式保留。框选过程遇到旋转时取消旧画面并提示重新框选，避免坐标错位。
- 静态教材取帧不再依赖等待后的下一次页面刷新：移除悬浮控件前清理旧帧，短暂保留移除后的画面，再进行有时间上限的读取，避免静止页面超时。

详细运行证据见 [verification.md](verification.md)。

## 液态玻璃与左右对话 · 2026-10-23

导航、输入与悬浮窗增加透镜边缘、分层高光及慢速光线。Windows 使用本页面背景的真实位移折射；Android 提供边缘光学模拟，主动截图预览时增加已有内存截图的局部透镜采样。没有为材质新增屏幕采集或外联。三处对话统一为用户靠右、导师靠左，流式历史与 Markdown/公式独立渲染。详细边界及验收见 [liquid-glass.md](liquid-glass.md)。
