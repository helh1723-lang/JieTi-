# 学习规划 0.2.1

学习规划由平铺建议改为课程目录与章节工作区。沿用现有暖白/松绿、深色主题和液态玻璃导航，以留白与细分隔线组织信息。

## 资料与范围

- 信号与系统 按用户提供的课程讲义划分为数学基础、第 1～7 章，共 52 个节级知识点。
- 所有章节和题目均纳入学习；不采用“暂不做”“不用做”的排除说明。
- 第六章在总讲义中只有目录，文件夹缺少正文。保留全部七节并显示“正文待补充”，不虚构页码。
- 第 1～5、7 章和数学基础对应分章 PDF 实际页码。Android 资料库上传同名讲义后可打开原页；也支持第 1～5 章合集的页码换算。
- 数学依据用户提供的高数、线代、概率强化板书及高数通关讲义，细分为高等数学 9 章（76 个知识点）、线性代数 6 章（36 个知识点）、概率论与数理统计 8 章（45 个知识点），共 23 章、157 个知识点。三大学科分别展开，不将旧的六个大类当作完整课程。数学资料的页码为已核对的章节/课次入口；不虚构手写板书每个知识点的精确页码。
- 仅随应用分发课程结构与页码，不打包用户 PDF 或本机资料路径。

## 行为

数学采用三大学科 → 章节 → 知识点的层级：

| 学科 | 章节 | 知识点 |
| --- | --- | --- |
| 高等数学 | 函数极限连续；一元微分；一元积分；多元微分；二重积分；微分方程；无穷级数；空间解析几何与几何应用；三重积分、曲线积分与曲面积分 | 76 |
| 线性代数 | 行列式；矩阵；向量组与向量空间；线性方程组；特征值特征向量与相似；二次型 | 36 |
| 概率论与数理统计 | 随机事件与概率；一维分布；多维分布；数字特征；大数定律与中心极限定理；数理统计与抽样分布；参数估计；假设检验 | 45 |

三份强化板书提供章节依据；高数通关讲义补充数学空间几何、三重积分和曲线/曲面积分的资料入口。知识点是对章节内容的结构化细分，不把板书课次起始页冒充每一知识点的精确页码。

目录展示章节与已掌握知识点数量。章节内整理学习要点、各节熟练度、本周重点及复习安排；每日三题和周计划显示章节归属。

熟练度沿用现有掌握快照：待诊断、巩固中、待复习、已掌握。无记录时不生成百分比；章节进度表示“已掌握节数 / 总节数”，不代表考试得分。同一节包含多个能力标签时保守合并，避免一个别名的掌握记录掩盖其他待复习记录。删除记录不参与统计。

知识点匹配优先精确名称和别名。名称含混或尚未收录的知识点保留在“待归类”，不删除原有计划与学习记录。目录、匹配规则和掌握状态语义在 Android / Windows 保持一致，课程结构来自同一份 `shared/curriculum.json`。

Android 将章节学习、每日三题、周计划设为三个入口。大屏使用目录与正文双栏，小屏使用可展开的章节选择器。每日三题的拍照、相册上传、提示与讲评流程继续沿用。

学习规划 Agent 接收章节结构及资料可用状态；冷启动的 信号与系统 诊断目标来自课程知识点，课程版本变化会使旧规划重新计算。
