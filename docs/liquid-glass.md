# 液态玻璃与对话排版 · 2026-10-23

## 调研与设计取舍

Apple 的 [Meet Liquid Glass](http[LOCAL_PATH]) 将 lensing、随几何形状变化的镜面高光、柔软形变和材质深度作为整体；[官方介绍](http[LOCAL_PATH]) 也明确包含对周围内容的反射与折射。模糊半透明底本身不足以构成这些特征。

截题将玻璃主要放在悬浮窗、导航和输入控件。正文继续保持清晰、宽敞；配色为暖白、石墨与淡苔绿。悬浮窗与悬浮球保留慢速边缘流动高光；普通按钮仅保留触摸涟漪。0.1.5 移除旧截图的材质采样，并新增悬浮球拖动形变。

## 实现范围

| 位置 | 实际实现 | 边界 |
|---|---|---|
| Windows 导航与主要控件 | 按圆角几何计算法线贴图，通过 SVG displacement 对当前页面背景产生凸透镜边缘位移；内侧薄高光、阴影与慢速边缘光线 | 只处理本应用页面背景，不读取桌面屏幕 |
| Android 悬浮球、小窗、输入框 | 透明材质、双层凸起轮廓、明暗边缘；悬浮球与小窗每9秒一圈流动高光，最多20Hz刷新 | 当前系统画面实时透过透明表面；边缘属于光照模拟，不使用冻结截图作折射 |
| Android 面板和展开菜单 | 支持设备使用系统实时窗口背景模糊；不支持时仅调整玻璃雾度，菜单雾度更强 | 不用历史截图模拟实时背景，不为材质新增屏幕采集 |
| Android 悬浮球拖动 | 0.1.6 提高慢速响应，前端鼓起、尾部收窄并产生身体滞后，停止移动后逐渐放松，松手后有可见弹性回摆；形变使用帧回调 | 仅改变绘制轮廓，实际窗口坐标、点击区域和回边位置不缩放；减少动态效果时停用形变 |
| Android 主应用 | 玻璃导航托盘、柔和选中态、输入框内缘高光与聚焦明度过渡 | Compose 控件采用几何光照模拟，没有声称实现 Apple 原生材质 |

Android 12 兼容路径不依赖 API 33 的 RuntimeShader。此次没有新增权限、外联资源或依赖包。模拟效果与 Apple 系统级 Liquid Glass 不等同。

## 悬浮窗按钮、位置与可读性

默认底部仅一条玻璃输入栏：左侧“＋”，中部可换行输入，右侧思考选择和发送／停止。截图、教学方式、学科、图解、重试和完成位于展开菜单；菜单内可直接选择具体教学方式。标题的收起、关闭与所有操作采用统一的深色文字和触摸涟漪，不再为每个按钮叠加白色或绿色底板。短窗口菜单限制高度并支持滚动。

截图时立即隐藏但保留已有窗口与 WebView，隐藏键盘后捕获；保存裁切结果放在 IO 线程。取消、补拍、预览、发送及 AI 返回均复用已有窗口。内存截图仅用于框选、重新裁切与发送预览，不参与面板、菜单、悬浮球的背景或边缘绘制，服务结束时释放。收起重开及旋转仍保留当前会话中的窗口位置和尺寸。

面板采用透明玻璃，正文 WebView、HTML body 与导师消息背景透明，不在收到回答时改变底色。用户消息仅采用微弱透明边框与底色。系统支持且启用跨窗口模糊时使用原生背景模糊，否则保持实时透视与雾度调整；不会为材质主动采集额外屏幕。

## 对话行为

- Android 主应用、Android 悬浮答疑和 Windows 答疑记录均为用户靠右、导师靠左。
- 用户气泡按内容收缩；导师回答留足公式、表格与图解的宽度。
- 消息以真实 role 字段区分，每条内容独立清洗后渲染 Markdown 和 KaTeX，不能通过正文里的“我／导师”文字改变身份。
- 悬浮窗监听当前题目的 Room 消息，流式片段与已保存历史合并显示；取消/报错保留未完成片段，但不保存为掌握证据。
- 原题、复盘与沙箱图解保持独立页面；流式追加不重复播放整个页面入场动画。

## 验证记录

Windows 的 `--glass-smoke` 在开发运行和打包后的可执行程序中通过：检查实际折射产生像素差异、右侧用户与左侧导师坐标、共享 Android 消息渲染器的公式、HTML 清洗及追加历史。`--motion-smoke` 检查页面与弹窗、输入伸缩、快速切换和减少动态效果。所有测试使用明确标注的自编题目，没有真实 AI 调用。

本轮 Android 模拟器主流程横竖屏11组检查通过；原生 `GlassAcceptanceTest` 两项检查通过，包括重复重绘、按钮中心衬底与深色文字的至少4.5:1对比度、离线发送前确认没有配置 API Key。窗口位置专项直接点击“发送”，比较系统报告的窗口矩形，并检查收起重开；测试消息带 `acceptance-only-position` 标记，不代表真实学习证据。

MuMu 在部分状态下忽略 `wm user-rotation`，测试驱动会识别唯一正在运行的实例，使用官方 `MuMuManager control tool func --name rotate` 入口，再以真实截图宽高验证方向，结束后恢复原方向和旋转设置。不会用分辨率窄窗口冒充旋转。

Android 最终构建、横竖屏、关闭释放与视觉证据见同目录 verification.md 和 evidence/liquid-glass/。这些记录只证明所列模拟器路径，不代替荣耀 V8 Pro 实机体验、真实 AIPING 解题效果或长时间帧率/耗电测试。
