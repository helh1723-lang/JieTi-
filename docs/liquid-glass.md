# 液态玻璃与对话排版 · 2026-10-23

## 调研与设计取舍

Apple 的 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 将 lensing、随几何形状变化的镜面高光、柔软形变和材质深度作为整体；[官方介绍](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/) 也明确包含对周围内容的反射与折射。模糊半透明底本身不足以构成这些特征。

截题将玻璃主要放在悬浮窗、导航和输入控件。正文继续保持清晰、宽敞；配色为暖白、石墨与淡苔绿。边缘光线缓慢移动，没有蓝紫渐变或整块发光遮罩。

## 实现范围

| 位置 | 实际实现 | 边界 |
|---|---|---|
| Windows 导航与主要控件 | 按圆角几何计算法线贴图，通过 SVG displacement 对当前页面背景产生凸透镜边缘位移；内侧薄高光、阴影与慢速边缘光线 | 只处理本应用页面背景，不读取桌面屏幕 |
| Android 悬浮球、小窗、输入框 | 透明材质、双层凸起轮廓、明暗边缘、9秒一圈的局部高光；显示期间以最多20Hz刷新高光，移除窗口后取消调度 | 常态下属于边缘光学模拟，没有对其他应用进行连续实时折射 |
| Android 截图预览小窗 | 现有的、用户主动框选取得的内存截图参与窄边缘的放大透镜采样 | 仍是当前冻结截图；不会为玻璃效果自动截图、额外保存或上传背景 |
| Android 主应用 | 玻璃导航托盘、柔和选中态、输入框内缘高光与聚焦明度过渡 | Compose 控件采用几何光照模拟，没有声称实现 Apple 原生材质 |

Android 12 兼容路径不依赖 API 33 的 RuntimeShader。此次没有新增权限、外联资源或依赖包。模拟效果与 Apple 系统级 Liquid Glass 不等同。

## 悬浮窗按钮、位置与可读性

“发送、停止、图解、补拍本题、完成、收起、关闭”统一采用薄厚度玻璃按钮：顶部高光、内侧暗缘与轻微外投影。发送使用淡绿玻璃，其余为暖白；使用深色中等字重文字，按钮不持续播放高光动画，按下时短暂下沉和回弹。缩小窗口后，操作栏可横向滚动。

关闭/重建答疑面板前保存 WindowManager 的位置与尺寸；发送、补充截图、收起后重新打开继续使用该矩形。横竖屏改变时仅将超出屏幕的部分约束回可见范围。位置保留作用于当前悬浮学习会话。

大面板采用约89%至96%的浅色材质，实际消息区域再叠加约94%的阅读衬底，边缘仍保留光学层。该方式不依赖跨应用模糊。修复共享画笔在描边后遗留低透明度、导致后续重绘过透明的问题。

## 对话行为

- Android 主应用、Android 悬浮答疑和 Windows 答疑记录均为用户靠右、导师靠左。
- 用户气泡按内容收缩；导师回答留足公式、表格与图解的宽度。
- 消息以真实 role 字段区分，每条内容独立清洗后渲染 Markdown 和 KaTeX，不能通过正文里的“我／导师”文字改变身份。
- 悬浮窗监听当前题目的 Room 消息，流式片段与已保存历史合并显示；取消/报错保留未完成片段，但不保存为掌握证据。
- 原题、复盘与沙箱图解保持独立页面；流式追加不重复播放整个页面入场动画。

## 验证记录

Windows 的 `--glass-smoke` 在开发运行和打包后的可执行程序中通过：检查实际折射产生像素差异、右侧用户与左侧导师坐标、共享 Android 消息渲染器的公式、HTML 清洗及追加历史。`--motion-smoke` 检查页面与弹窗、输入伸缩、快速切换和减少动态效果。所有测试使用明确标注的自编题目，没有真实 AI 调用。

本轮 Android 模拟器主流程横竖屏11组检查通过；原生 `GlassAcceptanceTest` 两项检查通过，包括重复重绘、按钮中心衬底与深色文字的至少4.5:1对比度、离线发送前确认没有配置 API Key。窗口位置专项直接点击“发送”，比较系统报告的窗口矩形，并检查收起重开；测试消息带 `acceptance-only-position` 标记，不代表真实学习证据。

MuMu 在部分状态下忽略 `wm user-rotation`，测试驱动会识别唯一正在运行的实例，使用官方 `MuMuManager control tool func --name rotate` 入口，再以真实截图宽高验证方向，结束后恢复原方向和旋转设置。不会用分辨率窄窗口冒充旋转。

Android 最终构建、横竖屏、关闭释放与视觉证据见同目录 verification.md 和 本地验收素材目录。这些记录只证明所列模拟器路径，不代替荣耀 V8 Pro 实机体验、真实 AIPING 解题效果或长时间帧率/耗电测试。
