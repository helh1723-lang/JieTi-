# 动效修订 · 2026-10-23

本轮沿用暖米白与绿色阅读界面，补上页面、组件和悬浮窗口的过渡。

| 位置 | 行为 |
|---|---|
| Windows 页面/题目/标签切换 | 旧内容短暂淡出，新内容淡入并轻移约10px；导航底色连续移动，文字保持可读 |
| Windows 编辑弹窗 | 遮罩渐入，弹窗小幅上移展开；支持在展开中直接关闭 |
| Windows 输入与折叠 | 笔记输入高度约220ms渐变，按钮轻微按压，支持的浏览器对详情折叠做约240ms过渡 |
| Android 主页面/题目 | 原生淡入和小幅位移，顶部导航随进入阅读平滑收起 |
| Android 小组件 | 标签底色/文字渐变，工具与记忆区展开收起，输入区柔和伸缩和聚焦抬升，发送键轻微回弹 |
| Android 答疑正文 | 切换原题/复盘/图解时短暂淡入；同一页面的流式更新不反复播放入场动画 |
| Android 悬浮控件 | 悬浮球约180ms、小窗约260ms展开；收起约130ms，拖动后约240ms贴边，按钮有短促按压反馈 |
| Android 关闭 | 先停止捕获和释放资源，再做约100ms的窗口淡出，随后移除窗口和服务 |

截图前始终立即隐藏全部悬浮控件，不通过等待淡出取得画面。关闭的清理不依赖动画结束回调；快速关闭、旋转和再次打开仍保留原有的生命周期保护。

页面动效只对用户导航和界面状态变化触发，不对每个流式字词、后台同步或列表数据刷新重复触发。没有添加常驻闪烁、漂浮循环或整页持续模糊。

## 验证

- `npm run verify`：构建与7项测试通过；Android 单元测试、lint、APK组装通过。
- Electron 实际运行检查记录动画状态与过渡帧；快速连续选择仍落在最后一次选择，弹窗和遮罩共同进入，展开中关闭后不残留弹窗，输入高度存在中间值。
- Electron 使用本窗口媒体仿真检查减少动画，动画数量为0；仿真结束后恢复窗口设置，不修改 Windows 系统偏好。
- Android 使用系统原生动画时长规则；Compose 使用系统动画缩放，悬浮 View 检查 `ValueAnimator.areAnimatorsEnabled()`。
- 模拟器暂时将动画缩放设为0，悬浮窗口仍能打开和彻底关闭；检查后恢复原设置。实际结果见 `evidence/motion/android-runtime.json`。
- 最终 APK 已安装到 Android 12 模拟器，横竖屏11组功能回归通过。一次 MuMu UiAutomation 的 Binder“Bad file descriptor”导致测试工具退出137，应用进程没有崩溃；工具读取增加了仅针对137的有限重试，完整复验通过。
- 不把帧记录解释为稳定60/120fps性能保证。荣耀实机、手写输入和真实 AIPING 效果仍沿用原验收边界。

原始结果见 动效检查（原始验收素材未公开） 和 横竖屏复验（原始验收素材未公开），桌面预览（原始验收素材未公开） 来自实际窗口捕获帧。

Android 实际录屏：主页面与工具区（原始验收素材未公开）、悬浮小窗（原始验收素材未公开）。录屏帧率和设备实际刷新率不同，视频用于展示界面变化，不作为帧率基准。
