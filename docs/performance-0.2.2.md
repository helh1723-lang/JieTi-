# Android 0.2.2 性能优化

> 历史记录补充（2026-10-26）：本次已在 HONOR ROD-W09 确认原安装实际为 0.2.2（12），并完成保留数据的 0.2.3（13）优化包升级。文末“安装被拒绝”为当时未更新的阶段记录；当前状态及实测以 [0.2.3 报告](performance-0.2.3.md) 为准。

本轮针对首次启动和进入学习规划的卡顿，保留 0.2.1 的课程目录及视觉风格。Windows 本轮未改动，沿用 0.2.1。

## 修复

- 课程名称匹配预编译规则，使用有界缓存；逐个知识点扫描全部掌握记录，改为每份资料快照一次聚合。章节计数、筛选和展示直接读取索引，不在界面绘制期间重做全文匹配。
- Room 数据只监听当前页面需要的记录种类，JSON 解码、排序与课程统计移到后台。学习规划不再让外层工作区同时读取一份无关的完整资料。
- 自动规划的证据整理、摘要和题源处理在后台调度器运行，页面可先展示，避免首开页面时启动协程又回到界面线程做重计算。
- 启动与同步后的掌握度维护，改为一次读取证据和批量读取来源日期；相同能力结论、相同证据且没有更新的来源时不再重复写快照。维护在事务中完成，避免读写期间覆盖新证据。
- 已解密配置在进程内按密文版本缓存，避免重复打开系统密钥库；磁盘存储仍使用原有 Android Keystore 与 AES-GCM。

未修改数据库版本、权限、模型设置、签名方式和用户的原始资料。使用覆盖安装升级，不卸载或清空数据。

## 验证边界

在 USB 连接的 HONOR ROD-W09、Android 14 上采集 0.2.1 基线，与升级后的同一门数学课程（157 个知识点）比较。冷启动为进程冷启动，系统文件缓存已有预热，不等同第一次安装后的绝对冷启动。页面准备计时包含 ADB 与 UI 自动化稳定等待，不能当作纯渲染时间；旧版本规划页面的帧统计没有返回有效样本，不估算其帧率。

完整数据和实际安装校验保存在 `docs/evidence/performance-022/`。自动化回归包含掌握度合并、未知标签、删除记录、缓存淘汰、批量维护幂等性、设置缓存失效、主线程心跳、日练与图片作答。

## 当前实机交付状态

0.2.2 已通过 36 项 JVM 单元测试、Lint、18 项原生回归及模拟器章节/日练/横竖屏界面验收。荣耀平板的覆盖安装返回 `INSTALL_FAILED_ABORTED: User rejected permissions`，设备仍为 0.2.1，因此尚无新版实机性能结果；不能据模拟器结果声称真实平板卡顿已解决。原有应用未卸载、资料未清空。
