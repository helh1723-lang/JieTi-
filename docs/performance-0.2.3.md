# Android 0.2.3 流畅度优化

本版本重点减少学习规划、课程和章节切换的重复工作。公开包使用通用教学配置，不预置学校、个人考试目标、历史学习观察或知识弱点。

## 修改

- 两门课共用稳定的掌握度订阅，切换时读取已经计算的快照。
- 掌握度与讲义链接分开更新；建库进度不重新生成未变化的课程统计与链接。
- 后台建立讲义索引，章节记忆关联结果，知识点使用稳定标识。
- 分课程保留章节与目录分组选择。
- 自动规划在页面稳定后启动，合并重复导航请求，另一课程等待已有任务完成。手动更新和证据任务仍可触发更新。
- `tablet` 变体关闭 Debug，启用 R8 与资源压缩。数据库仍为 Room v2，保留迁移、原资料与用户设置。

## 性能证据的范围

下表来自维护者在 Android 14 荣耀平板上对同版个人构建的短时采样。公开通用包另从脱敏源码构建并验证，**这些数值不是公开 APK 在每台设备上的性能保证**。

每组在原数据和既有自动规划配置下，交替切换两门课程 6 次，点击间等待 700ms。统计使用 Android gfxinfo 汇总；测量窗口内不调用 UI 层级转储。

| 构建 | 帧数 | 卡顿帧 | P95 | P99 |
|---|---:|---:|---:|---:|
| 0.2.2 Debug | 834 | 23 | 20ms | 150ms |
| 0.2.3 Debug | 750 | 20 | 19ms | 48ms |
| 0.2.3 R8 优化构建 | 695 | 0 | 10ms | 11ms |
| 0.2.3 R8 重复采样 | 565 | 2 | 11ms | 12ms |

优化版另一个章节切换窗口记录到 573 帧、3 个卡顿帧、P95 11ms、P99 13ms。该窗口前置条件不同，单独报告。

采样会受温度、后台任务、自动规划阶段、系统缓存和数据量影响。P99 是帧耗时，不是点击响应时间。没有合格逐帧记录时，采样脚本会输出缺测，而不会当作零卡顿。厂商 Perfetto 事件存在导入缺口，未据此声称完整的逐函数归因。

## 验证与后续范围

公开源码的构建、单元测试、Lint、源码及 APK 脱敏扫描、实际公开 APK 启动与课程切换结果，见 [公开发布验证](public-release-0.2.3.md)。此前个人构建还完成了 18 项原生回归、章节/筛选/日练/横竖屏检查，以及原数据库、资源哈希、加密设置和真实 PDF 原页的保留校验；它们与公开包验证分开记录。

应用专用 Baseline Profile 尚未生成。长时间温控、大量真实资料建库、多个后台任务及完整在线教学效果仍需后续验收。个人模型配置和原始诊断素材不公开。
