# Android 0.2.3 平板流畅度修复验收约定

## 当前问题与预期

来源：用户授权按“排查平板卡顿原因”聊天中的建议实施，重点为学习规划、课程及章节切换。

- 0.2.2 的课程统计订阅绑定 subject；切课重新解码、聚合，并可能取消已启动的自动规划。
- 资料记录的建库进度和讲义链接混在同一输入内；无关进度更新会带来课程统计与界面更新。
- 章节构建中逐知识点扫描讲义、匹配薄弱点与计划。
- 交付使用 Debug；本轮提供非 Debug、R8 优化的 tablet 变体，保持已安装个人版的签名兼容。正式 release 不植入个人调试签名。

预期：两门课共用稳定订阅，在课程切换时直接读取已计算快照；资料处理进度不刷新掌握度或未变化的讲义链接；章节关联信息只在输入变化时生成；快速切课取消尚未启动的延迟请求，已启动的自动规划由应用作用域持有并合并请求。手动更新、后台证据触发、每日跟进保持可用。

## 回归预算

- 不改变学科范围、全部课程章节、掌握度保守合并、未知知识点与删除记录规则。
- 不改变自动规划开关、每日三题选题规则、题目条件、讲评、用户资料和原始文件。
- 数据库仍为 Room v2，无新增权限、网络接口或设置迁移。
- 讲义跳转保留同学科限制、单章优先、合订本偏移、页数边界和缺正文保护。
- 平板只覆盖升级，安装前核对证书；不卸载、不清数据。私有备份及原 APK 在 `.runtime/performance-023/`，不得发布。

## 验证矩阵

| 项目 | 证据要求 |
|---|---|
| 逻辑与映射 | JVM 全量回归，新增资料进度去重、页数/名称/学科/删除失效、合订本回退、掌握度合并测试 |
| Room 活数据 | 独立测试库连续更新资料进度，不触发课程统计和链接更新；真实掌握度更新和资料删除仍生效 |
| 包体 | Debug 与 tablet 单元测试/Lint/组装；检查 0.2.3(13)、非 Debug、R8、资源压缩、签名兼容 |
| 模拟器 | 原生回归、课程/章节/筛选/周计划/日练导航；区分样例数据与真实数据 |
| 平板 | 原有数据下覆盖安装、启动、同次数课程/章节切换、滚动、无新增崩溃/ANR |
| 性能 | 同设备、现有配置，记录 gfxinfo 汇总和 Perfetto；逐帧 Flags 不符合条件时标缺测，不计为零卡顿 |

正式性能结论写入 `performance-0.2.3.md`。自动化层级等待耗时不作为点击响应时间。短时采样不证明长时间发热、全部资料建库负载、所有设备或持续 60fps。应用专用 Baseline Profile 需单独生成和验证，不能用普通导航测试冒充。
