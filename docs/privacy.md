# 公开发布与隐私

公开代码和安装包使用通用教学配置，不预置个人学校、经历、考试目标、历史知识弱点或学习记录。资料、题目、记忆和模型设置由使用者在自己的设备上建立。

发布使用独立源码副本。排除环境配置、私钥、签名库、数据库、设备配对凭据、原始教材、题目截图、设备日志和构建缓存。源码和 APK 解包内容均经过敏感值扫描，Release 提供 SHA-256 校验文件。

公开 APK 从脱敏源码重新构建，不直接上传维护者平板上的个人包。签名公钥证书可以公开，私钥不会进入仓库或发布资产。当前公开 APK 为非 Debug 的 R8 优化构建，使用个人测试签名，并非应用商店生产签名。

API Key 由使用者配置，在 Android Keystore 加密后保存在设备中，不打包进应用，也不进入同步包和复盘导出。题目、图片和对话会按用户操作发送到其配置的模型与搜索服务；离线文字检索无需模型接口。

覆盖安装保留已有记录和设置，脱敏发布不会清空已经存储的用户数据。发布副本不修改维护者的私人教学提示词和本地配置。
