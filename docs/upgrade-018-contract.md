# 0.1.8 范围与验收契约

仅实现用户选定的七项优化及悬浮配色：连续离线版本链、旧分析失效、学科手动优先、持久当前条件、公式图表保真、资料记录去重、原图缩放圈选追问。

保留：本地学习数据、数据库保留数据迁移、删除/遗忘墓碑、同字段真实分叉冲突、草稿、渐进提示和既有透明玻璃材质。导出范围与结构化图解不在本轮。

验收：两端分别连续编辑10次、分叉异字段和同字段、同步中再次编辑；归档和核验中修改条件不得写旧结论/证据；跨学科检索不改手工学科；40条以外条件仍入提示；有正文的公式/图形页必须视觉复核，失败保留文字和质量提示；重复导入复用记录、显式独立/新版本保留来源；缩放圈选带原图坐标与裁图发送；预选和自定颜色持久生效并保护阅读对比度。

使用 STANDARD 构建检查加模拟器安装、仪器测试、界面观察和授权真实API抽验。模拟器不代替荣耀平板的权限、手写笔和保活证据。
