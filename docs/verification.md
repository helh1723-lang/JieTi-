# 验证范围

0.1.1 开发阶段已通过桌面构建、13 项 Node 回归、10 项 Android JVM 测试、Android lint 与 Debug APK 构建，以及 MuMu Android 12 模拟器上的 7 项原生测试。桌面发布包中的管理、删除、公式和连续对话界面也进行了合成数据验收。

公开源码副本另外运行 `npm run verify` 检查桌面构建及 Node 回归。原始设备日志、运行数据库和本机路径不随公开仓库发布。

这些检查不等于真实模型效果或真机保证。实际 AIPING 语义理解、视觉 OCR、长时间 SSE、教学评测效果和目标平板的手写笔、保活、键盘及长时间悬浮体验仍需真实环境验证。

同步两端需同时更新到 0.1.1。Room 数据库版本 2 保留 1→2 迁移，不使用破坏性清库。
